# Intel Wi-Fi & Bluetooth Driver Manager 2.1.0

## Алгоритм

1. Проверяет права администратора. В интерактивном режиме предлагает перезапуск через UAC; в автоматическом режиме требует заранее повышенных прав.
2. Показывает адаптеры Intel и текущие версии через Win32_PnPSignedDriver. Если подходящих устройств нет, завершает работу с ошибкой.
3. Проверяет NuGet и получает метаданные пакета из PSGallery. Сравнивает имя пакета, автора Marcin Grygiel и адрес проекта FirstEverTech/Universal-Intel-WiFi-BT-Updater.
4. Проверяет локальный файл в `%LOCALAPPDATA%\IntelWiFiBTManager\Updater`. При отсутствии или несовпадении версии/метаданных скачивает конкретную версию через Save-Script во временную подпапку, проверяет метаданные файла и заменяет локальную копию.
5. Запускает базовую утилиту в Windows PowerShell. В обычном режиме она управляет показом версий и подтверждениями. При `-Silent` передаётся `-auto`.
6. Дожидается завершения процесса. Ненулевой код дочернего процесса отображает как ошибку; менеджер возвращает 1. Нулевой код возвращает как 0 и в интерактивном режиме ожидает Enter.

## Ограничения

Метаданные автора и проекта не являются цифровой подписью и не гарантируют целостность кода. Проверки драйверов, создание точки восстановления и установка реализованы базовой утилитой. Успешное завершение процесса не заменяет проверку фактической версии драйвера после установки.

Менеджер не использует Get-InstalledScript, Install-Script или Update-Script. Сведения InstalledLocation не влияют на выбор файла. Путь к самому менеджеру может быть произвольным.

`-Silent` означает автоматическое подтверждение действий, а не скрытое окно или отсутствие консольного вывода. Поведение автоматического режима определяется базовой утилитой; этот режим ещё не проверен на пользовательском ПК.

Для работы нужны Windows, Windows PowerShell 5.1, PowerShellGet и доступ к PSGallery, GitHub и источникам драйверов базовой утилиты. Ошибки сетевых запросов обрабатываются без проверки доступности через ICMP/ping.
