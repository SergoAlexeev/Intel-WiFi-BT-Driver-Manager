# Полное руководство пользователя и техническое описание
### Менеджер Wi-Fi и Bluetooth Intel (Версия 2.0)

Данный документ содержит исчерпывающее техническое описание скрипта `IntelWiFiBTManager.ps1`, алгоритмы его работы, инструкции по развертыванию в корпоративной среде и руководство по устранению неполадок.

---

## ⚙️ Системные требования

* **Операционная система:** Windows 10 / Windows 11 (только 64-разрядные версии).
* **Права доступа:** Права локального администратора (необходимы для инсталляции системного ПО и управления точками восстановления).
* **Среда выполнения:** PowerShell версии 5.1 или новее.
* **Сеть:** Доступ к сети Интернет (для обращения к серверам обновлений Intel и Microsoft Update Catalog).
* **Зависимости:** Модуль `PowerShellGet` (по умолчанию интегрирован в современные версии Windows 10/11).

---

## 🛠 Пошаговый алгоритм работы скрипта

При запуске менеджер последовательно выполняет 12 этапов логики:

1. **Информационное сообщение:** Выводит в консоль сведения о назначении утилиты и требованиях к правам (подавляется в режиме `-Silent`).
2. **Проверка привилегий:** Проверяет роль администратора. В интерактивном режиме запрашивает UAC-перезапуск. В тихом режиме — немедленно завершает работу с кодом `1` при нехватке прав.
3. **Проверка интернета:** Выполняет проверочный пинг к серверам DNS (`8.8.8.8`). Если сеть недоступна, аварийно завершает работу, предотвращая зависание зависимых процессов.
4. **Сканирование оборудования:** Вызывает WMI/CIM-запрос к `Win32_PnPSignedDriver` для поиска физических Wi-Fi и Bluetooth адаптеров.
5. **Валидация производителя:** Проверяет наличие оборудования Intel. Если беспроводных адаптеров Intel нет в таблице найденных устройств, скрипт завершает работу с кодом `1`.
6. **Управление NuGet:** Проверяет наличие зарегистрированного PackageProvider NuGet в системе. При отсутствии — скачивает и устанавливает его локально для текущего пользователя.
7. **Управление движком поиска:** Ищет установленный скрипт `universal-intel-wifi-bt-driver-updater`. Если он отсутствует — ставит его. Если присутствует — запрашивает сервер на предмет наличия новой версии движка и обновляет его (в тихом режиме — автоматически).
8. **Чтение текущих версий:** Опрашивает Диспетчер устройств Windows и фиксирует текущие активные версии драйверов беспроводной сети на ПК.
9. **Запрос доступных версий:** Запускает движок во временном буфере с ключами `-auto -json`. Выполняет парсинг JSON-вывода. При обнаружении ошибок структуры переходит к Regex-парсингу текстового лога.
10. **Отрисовка отчета:** Формирует и выводит в консоль сводную таблицу сравнения версий драйверов с цветовым выделением («Актуален» — зеленый, «Доступно обновление» — желтый).
11. **Установка обновлений:** 
    * В интерактивном режиме: запрашивает подтверждение `(Y/N)`.
    * В режиме `-Silent`: автоматически переходит к установке, если обнаружено расхождение версий.
12. **Завершение:** Утилита удаляет за собой созданные временные файлы, выводит рекомендацию по перезагрузке ОС и возвращает код `0`.

## 📂 Инструкция по ручной установке и созданию ярлыка

1. Скопируйте файл `IntelWiFiBTManager.ps1` в постоянный каталог, например: `C:\Scripts\`.
2. Создайте ярлык быстрого запуска в меню «Пуск»:
   * Нажмите ПКМ на рабочем столе → **Создать** → **Ярлык**.
   * В поле «Укажите расположение объекта» вставьте команду:
     ```cmd
     powershell.exe -ExecutionPolicy Bypass -NoProfile -File "C:\Scripts\IntelWiFiBTManager.ps1"
     ```
   * Назовите ярлык: `Intel Wi-Fi & BT Manager`.
   * Переместите созданный ярлык в системный каталог:
     `%AppData%\Microsoft\Windows\Start Menu\Programs`.

## 📜 История изменений проекта

* **Версия 2.0 (Текущая)** — Пройден независимый SecOps-аудит безопасности. Введена принудительная верификация издателя пакета в репозитории PSGallery для исключения рисков тайпосквоттинга и подмены кода. Добавлена строгая валидация распарсенных Regex-переменных, защищающая логику от ложных статусов актуальности драйверов при сбое структуры данных.
* **Версия 1.9 (09.09.2026)** — Внедрены явные коды завершения (Exit 0 / Exit 1) для интеграции в системы мониторинга. Исправлены логические ошибки тихого режима: полностью ликвидированы интерактивные вызовы Read-Host в нештатных ситуациях (отсутствие сети, отсутствие прав).
* **Версия 1.8** — Добавлен стартовый пинг-тест доступности сети. Реализован парсинг данных в формате JSON с мягким откатом на регулярные выражения (Regex). Разработан тихий ключ `-Silent` для планировщиков.
* **Версия 1.7** — Оптимизирована логика выхода: мгновенное завершение работы при обнаружении оборудования сторонних производителей (без лишних запросов).
* **Версии 1.1 – 1.6** — Эволюция проекта: добавлен вывод графических интерактивных таблиц, динамическое определение точных индексов моделей адаптеров (AX200, AX210, BE200) вместо статических строк, автоматическая установка NuGet и самообновление исполняемого движка.
* **Версия 1.0** — Базовый релиз. Проверка Wi-Fi и Bluetooth через CLI-утилиту, русскоязычный консольный интерфейс.
