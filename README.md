# Intel Wi-Fi & Bluetooth Driver Manager (v1.9)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Platform: Windows](https://shields.io)](https://microsoft.com)
[![Language: PowerShell](https://shields.io)](https://microsoft.com)


Автоматизированный PowerShell-скрипт для проверки, скачивания и чистой установки актуальных драйверов беспроводных адаптеров **Intel Wi-Fi** и **Intel Wireless Bluetooth**.

Менеджер выступает в роли умной, легковесной и безопасной оболочки (wrapper) для консольной утилиты `universal-intel-wifi-bt-driver-updater`. Он адаптирует её возможности как для обычных пользователей (интерактивный русский интерфейс), так и для системных администраторов (полноценный тихий режим автоматизации).

---

## 🚀 Основные преимущества менеджера

* **Защита «от дурака»:** Скрипт сканирует систему перед запуском. Если беспроводные чипы Intel отсутствуют (например, установлены Realtek или Qualcomm), работа безопасно прекращается без засорения системы лишними файлами.
* **Устойчивый гибридный парсинг:** Для проверки версий менеджер запрашивает структурированный JSON-вывод. В случае сбоя или несовместимости версий движка код мгновенно переключается на резервный алгоритм регулярных выражений (Regex).
* **Полная автономность:** На чистой Windows скрипт самостоятельно развернет поставщика NuGet и скачает актуальную версию базовой CLI-утилиты.
* **Безопасность развертывания:** Перед любой установкой драйверов скрипт инициирует создание системной точки восстановления Windows.

## 📦 Варианты запуска и параметры

### 1. Интерактивный режим (для пользователей)
Запуск двойным кликом по ярлыку или из консоли. Выводит наглядную таблицу сравнения версий и запрашивает подтверждение перед установкой обновлений:
```powershell
.\IntelWiFiBTManager.ps1
```
*Если скрипт запущен без прав администратора, он автоматически отобразит окно запроса UAC.*

### 2. Тихий режим (для системных администраторов)
Предназначен для фонового обновления парка ПК через **GPO, SCCM, MDT, Task Scheduler** или системы мониторинга. Подавляет любые диалоговые окна и запросы ввода `(Y/N)`:
```powershell
.\IntelWiFiBTManager.ps1 -Silent
```
*Важно: в тихом режиме скрипт требует предварительного запуска с повышенными правами администратора (например, из-под учетной записи `SYSTEM`). При нехватке привилегий или отсутствии интернета скрипт не падает в бесконечное ожидание, а завершается с кодом ошибки.*

## 📊 Коды завершения (Exit Codes)

Скрипт возвращает стандартизированные коды завершения, что позволяет интегрировать его в корпоративные системы мониторинга (Zabbix, Nagios и др.):
* **`0`** — Успешно: драйверы обновлены до актуальных версий либо обновление не требовалось.
* **`1`** — Критическая ошибка: нет интернета, нет прав администратора в режиме `-Silent`, либо в системе отсутствуют адаптеры Intel.
