# Intel Wi-Fi & Bluetooth Driver Manager v2.2.0 preview

Менеджер Wi-Fi и Bluetooth Intel на PowerShell. Для установки использует [Universal Intel Wi-Fi and Bluetooth Drivers Updater](https://github.com/FirstEverTech/Universal-Intel-WiFi-BT-Updater). Требуются Windows 10/11, PowerShell 5.1+, адаптер Intel, подключение к интернету и права администратора. Установка драйверов выполняется базовой утилитой.

## Запуск

Откройте PowerShell и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\IntelWiFiBTManager.ps1
```

После подтверждения UAC менеджер проверит адаптеры, метаданные пакета в PowerShell Gallery и при необходимости предложит скачать или обновить локальную копию базовой утилиты. Затем базовая утилита покажет сведения о драйверах и запросит подтверждение установки по своим правилам.

При интерактивном запуске сначала выберите язык сообщений менеджера: `1` — русский, `2` — английский (Enter выбирает русский). Можно пропустить вопрос параметром `-Language ru` или `-Language en`. Выбор сохраняется при перезапуске через UAC. Экраны сторонней базовой утилиты Wi-Fi/Bluetooth и установщика Intel остаются на языке этих программ; менеджер не переводит их интерфейс. В `-Silent` вопрос не выводится, по умолчанию используются русские сообщения.

Автоматический режим (запускайте уже от администратора):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\IntelWiFiBTManager.ps1 -Silent
```

`-Silent` скачивает базовую утилиту и запускает ее с `-auto`: доступные обновления драйверов могут устанавливаться без подтверждения. Этот режим пока не проверен на пользовательском ПК; запускайте его только после проверки интерактивного режима. Код завершения: `0` при успехе, `1` при ошибке. Менеджер сравнивает имя, автора и адрес проекта в метаданных PSGallery; это **не** проверка цифровой подписи пакета. Поведение проверки и установки драйверов определяется базовой утилитой.

## Расположение файлов

Менеджер можно сохранить в любую папку. Базовая утилита скачивается через `Save-Script` в `%LOCALAPPDATA%\IntelWiFiBTManager\Updater`. Записи `Get-InstalledScript` и сохранённые в них абсолютные пути не используются. Перед запуском проверяются метаданные локального файла и доступная версия PSGallery.

Предыдущий релиз [v2.0](https://github.com/SergoAlexeev/Intel-WiFi-BT-Driver-Manager/releases/tag/v2.0) содержит ошибку проверки автора; используйте v2.1.0.

## Предварительный режим Intel Graphics

Отдельный интерактивный режим предварительно распознаёт графику Intel HD, UHD или Iris Plus у некоторых Intel Core i3/i5/i7/i9 7–10 поколений с Windows 10 (начиная с 1809) или Windows 11 x64. Проверяются поколение процессора, класс устройства, Intel PCI Vendor ID и семейство графики; это не полный список PCI Device ID из INF. Окончательную совместимость определяет установщик Intel. При неизвестном сочетании менеджер останавливается до загрузки. NVIDIA не затрагивается; обычный запуск Wi-Fi/Bluetooth не меняется. Пакет Intel Graphics 31.0.101.2145 от 22 сентября 2026 года загружается с официального сервера Intel в локальный кэш. Региональные ограничения могут помешать загрузке.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\IntelWiFiBTManager.ps1 -Graphics
```

Если автоматическая загрузка недоступна, можно скачать `gfx_win_101.2145.exe` с [официальной страницы Intel](https://www.intel.com/content/www/us/en/download/776137/intel-7th-10th-gen-processor-graphics-windows.html) и указать путь через `-GraphicsInstallerPath`. Перед запуском менеджер сверяет SHA-512 с опубликованным Intel значением и действительную цифровую подпись Intel, затем запрашивает подтверждение. Установщик сам показывает лицензию и проверяет совместимость. Универсальный пакет Intel может заменить драйвер, настроенный производителем ноутбука. На одной системе с Windows 11 проверено обновление Intel UHD Graphics до 31.0.101.2145 и сохранение новой версии после перезагрузки. Другие компьютеры пока не испытаны. `-Silent` для этого режима недоступен.

После закрытия установщика менеджер повторно проверяет версию и предлагает перезагрузку с отдельным подтверждением, если версия подтверждена либо установщик вернул документированный код успеха или необходимости перезагрузки. На испытанном ПК установщик вернул код `1000`, но новая версия уже была видна Windows; этот код сам по себе не считается подтверждением успеха. При неизвестном коде и неизменившейся версии перезагрузка не предлагается: проверьте журнал Intel `%ProgramData%\Intel\GFXInstaller\IntelGfx.log`. Отказ от предложенной перезагрузки завершает менеджер без ошибки; перезагрузить компьютер можно позднее вручную.

Логика выбора пакета и предложения перезагрузки проверяется без установки и без настоящей перезагрузки: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\RestartPrompt.Tests.ps1`. Полный сценарий обновления на других устройствах пока не проверен.

Для PR настроена проверка GitHub Actions на Windows PowerShell 5.1: запускаются этот безопасный тест и `-Inventory -Language en`. CI не скачивает драйверы и не запускает установщики; проверку реальной установки на другом оборудовании он не заменяет.

## Проверка обновлений без установки

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\IntelWiFiBTManager.ps1 -CheckUpdates
```

Режим не требует прав администратора, не скачивает драйверы и не запускает установщики. Для каждого обнаруженного устройства Intel Wi-Fi, Bluetooth и Graphics показывает установленную версию, доступную для сравнения версию и статус. Wi-Fi/Bluetooth сверяются по точному PCI/USB ID: для подтверждённого по экспортированному INF Wi-Fi `PCI\\VEN_8086&DEV_02F0&SUBSYS_00748086` и Bluetooth `USB:0026` используется локальный справочный снимок версий от 27 сентября 2026 года. Анализ INF показал, что `DEV_02F0` встречается у разных моделей с разными `SUBSYS`, поэтому локальная Wi-Fi запись применяется только при совпадении полного DEV+SUBSYS; версия установленного пакета не подтверждает совместимость будущего пакета; после 30 дней сравнение по нему отключается до пересмотра. Для остальных ID временно используются общедоступные таблицы FirstEverTech. Снимок не является живым каталогом Intel и не подтверждает новых выпусков после своей даты. Для Graphics используется закреплённый пакет Intel 31.0.101.2145 только при успешной проверке семейства. Источники версий выводятся после таблицы. Установка Wi-Fi/Bluetooth по-прежнему выполняется сторонней базовой утилитой.

Отчёт сначала показывает процессор и Windows, затем для каждого устройства источник сравнения, результат и понятный следующий шаг. Для графики Intel Core 6-го поколения он показывает статус «Требуется ручная проверка» и ссылку на архивный пакет Intel 31.0.101.2115: это справочный ориентир, а не подтверждённое обновление для текущей Windows. Для графики Core 11–14 поколений и Arc/Core Ultra отчёт определяет семейство и даёт ссылку на страницу Intel для ручной проверки, но пока не сравнивает версии и не предлагает установку. Выбор этих семейств не расширяет установленный пакет Graphics 7–10 поколений. Если в компьютере нет Intel Wi-Fi/Bluetooth, отчёт не обращается к их сетевым таблицам. Беспроводные устройства Qualcomm и других производителей показываются отдельно с рекомендацией проверить точную модель компьютера на странице его производителя; модуль Intel для них не подходит. Программа пока не определяет наличие обновлений для таких устройств и не запускает их установку.

«Доступно обновление» — предварительное уведомление по таблице, а не гарантия, что пакет скачивается, подходит конкретной OEM-системе и установится. «Версия совпадает» означает совпадение с выбранным источником, а не проверку всех возможных обновлений Intel. При отсутствии записи, недоступной сети, изменении формата таблиц или неподдерживаемом оборудовании выводится «Не удалось определить»; никаких действий по установке не происходит. Чипсет, BIOS и микрокод в этом режиме пока не проверяются. Для обновления пользователь отдельно запускает обычный режим Wi-Fi/Bluetooth или `-Graphics` и подтверждает действия.

## Инвентаризация для будущих модулей

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\IntelWiFiBTManager.ps1 -Inventory
```

Команда показывает модель компьютера, CPU, Windows, BIOS и версии устройств Intel (графика, сеть, Bluetooth, системные и программные компоненты). Она не требует прав администратора, ничего не скачивает и не устанавливает. Это основа для выбора совместимых пакетов по конкретному устройству и изготовителю ПК. Наличие новой версии по одной записи в таблице не определяется.

## Журнал работы

Каждый запуск записывается в отдельный файл `%LOCALAPPDATA%\IntelWiFiBTManager\Logs\manager-*.log`. Путь выводится в начале и в конце работы. Запрос UAC продолжает тот же файл журнала после повышения прав. В нём сохраняются сообщения скрипта, результаты проверок, ошибки и коды завершения. Внешние графические окна установщика Intel и возможный вывод дочерней Wi-Fi/Bluetooth утилиты, который минует PowerShell-хост менеджера, журнал PowerShell не гарантирует записать. Для них доступны собственные журналы и коды завершения.

«Драйвер чипсета» может означать INF для обозначения устройств, отдельные платформенные драйверы или обновление BIOS с микрокодом. Автоматическая установка такого пакета пока не реализована: для неё потребуются источник от производителя компьютера или Intel, проверка аппаратных ID и версии Windows, контроль подписи и отдельное подтверждение.

## Отчёт по распакованным INF (для разработки)

Отдельный инструмент читает уже распакованные INF из указанной папки и сохраняет соответствия аппаратных ID, версий `DriverVer` и секций Windows в JSON:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Get-InfDriverReport.ps1 -Path 'C:\Drivers\Extracted' -OutputPath '.\inf-report.json'
```

Без `-OutputPath` выводится таблица. Инструмент не скачивает CAB, не проверяет цифровые подписи и не устанавливает драйверы. Имя секции INF показывает указанное изготовителем ограничение платформы, но само по себе не доказывает совместимость с данным компьютером. Перед добавлением записи в локальный каталог нужны проверка происхождения и подписи пакета, сопоставление всех аппаратных ID и ручной просмотр результата. Тест: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\InfReport.Tests.ps1`.

### Сравнение двух INF отчётов

Когда появится проверяемый кандидатный пакет, сформируйте для него второй JSON тем же генератором. Для конкретного PCI/USB ID сравните отчёты:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Compare-InfDriverReports.ps1 -InstalledReport '.\installed.json' -CandidateReport '.\candidate.json' -HardwareId 'PCI\VEN_8086&DEV_02F0&SUBSYS_00748086'
```

Инструмент предпочитает точное совпадение ID и показывает, когда в INF есть только более общий ID; при отсутствии совпадения не предлагает обновление. Сравнение версий не заменяет проверку происхождения, хеша, подписи, Windows, OEM-настроек и выбора драйвера системой. Скачивания и установки нет.
