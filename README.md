# Intel Wi-Fi & Bluetooth Driver Manager v2.2.0 preview

Оболочка PowerShell для [Universal Intel Wi-Fi and Bluetooth Drivers Updater](https://github.com/FirstEverTech/Universal-Intel-WiFi-BT-Updater). Требуются Windows 10/11, PowerShell 5.1+, адаптер Intel, подключение к интернету и права администратора. Установка драйверов выполняется базовой утилитой.

## Запуск

Откройте PowerShell и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\IntelWiFiBTManager.ps1
```

После подтверждения UAC менеджер проверит адаптеры, метаданные пакета в PowerShell Gallery и при необходимости предложит скачать или обновить локальную копию базовой утилиты. Затем базовая утилита покажет сведения о драйверах и запросит подтверждение установки по своим правилам.

Автоматический режим (запускайте уже от администратора):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\IntelWiFiBTManager.ps1 -Silent
```

`-Silent` скачивает базовую утилиту и запускает ее с `-auto`: доступные обновления драйверов устанавливаются без подтверждения. Код завершения: `0` при успехе, `1` при ошибке. Менеджер сравнивает имя, автора и адрес проекта в метаданных PSGallery; это **не** проверка цифровой подписи пакета. Поведение проверки и установки драйверов определяется базовой утилитой.

## Расположение файлов

Менеджер можно сохранить в любую папку. Базовая утилита скачивается через `Save-Script` в `%LOCALAPPDATA%\IntelWiFiBTManager\Updater`. Записи `Get-InstalledScript` и сохранённые в них абсолютные пути не используются. Перед запуском проверяются метаданные локального файла и доступная версия PSGallery.

## Проверка версии 2.1.0

Проверены интерактивный запуск, загрузка в локальное хранилище, отказ от обновления с кодом 0, обновление Bluetooth и повторное обнаружение актуальных драйверов. Автоматический режим `-Silent` и запуск на чистой Windows пока не проверены.

## Предварительный режим Intel Graphics

Отдельный интерактивный режим поддерживает Intel UHD Graphics на i7-10710U с Windows 11 x64. Он не обновляет NVIDIA и не меняет обычный запуск Wi-Fi/Bluetooth. Пакет Intel Graphics 31.0.101.2145 от 22 сентября 2026 года загружается с официального сервера Intel в локальный кэш. Региональные ограничения могут помешать загрузке.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\IntelWiFiBTManager.ps1 -Graphics
```

Если автоматическая загрузка недоступна, можно скачать `gfx_win_101.2145.exe` с [официальной страницы Intel](https://www.intel.com/content/www/us/en/download/776137/intel-7th-10th-gen-processor-graphics-windows.html) и указать путь через `-GraphicsInstallerPath`. Перед запуском менеджер сверяет SHA-512 с опубликованным Intel значением и действительную цифровую подпись Intel, затем запрашивает подтверждение. Установщик сам показывает лицензию и проверяет совместимость. Универсальный пакет Intel может заменить драйвер, настроенный производителем ноутбука. На одной системе с Windows 11 проверено обновление Intel UHD Graphics до 31.0.101.2145 и сохранение новой версии после перезагрузки. Другие компьютеры пока не испытаны. `-Silent` для этого режима недоступен.

После закрытия установщика менеджер повторно проверяет версию и предлагает перезагрузку с отдельным подтверждением, если версия подтверждена либо установщик вернул документированный код успеха или необходимости перезагрузки. На испытанном ПК установщик вернул код `1000`, но новая версия уже была видна Windows; этот код сам по себе не считается подтверждением успеха. При неизвестном коде и неизменившейся версии перезагрузка не предлагается: проверьте журнал Intel `%ProgramData%\Intel\GFXInstaller\IntelGfx.log`. Отказ от предложенной перезагрузки завершает менеджер без ошибки; перезагрузить компьютер можно позднее вручную.

Логика предложения перезагрузки проверяется без установки и без настоящей перезагрузки: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\RestartPrompt.Tests.ps1`. Полный сценарий запроса после новой установки пока не проверен.

## Инвентаризация для будущих модулей

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\IntelWiFiBTManager.ps1 -Inventory
```

Команда показывает модель компьютера, CPU, Windows, BIOS и версии устройств Intel (графика, сеть, Bluetooth, системные и программные компоненты). Она не требует прав администратора, ничего не скачивает и не устанавливает. Это основа для выбора совместимых пакетов по конкретному устройству и изготовителю ПК. Наличие новой версии по одной записи в таблице не определяется.

## Журнал работы

Каждый запуск записывается в отдельный файл `%LOCALAPPDATA%\IntelWiFiBTManager\Logs\manager-*.log`. Путь выводится в начале и в конце работы. Запрос UAC продолжает тот же файл журнала после повышения прав. В нём сохраняются сообщения скрипта, результаты проверок, ошибки и коды завершения. Внешние графические окна установщика Intel и возможный вывод дочерней Wi-Fi/Bluetooth утилиты, который минует PowerShell-хост менеджера, журнал PowerShell не гарантирует записать. Для них доступны собственные журналы и коды завершения.

«Драйвер чипсета» может означать INF для обозначения устройств, отдельные платформенные драйверы или обновление BIOS с микрокодом. Автоматическая установка такого пакета пока не реализована: для неё потребуются источник от производителя компьютера или Intel, проверка аппаратных ID и версии Windows, контроль подписи и отдельное подтверждение.
