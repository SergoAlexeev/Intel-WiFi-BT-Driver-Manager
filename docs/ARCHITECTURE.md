# Текущая архитектура

Аудит: 2026-10-01, рабочая ветка `feature/intel-graphics-preview`, исходный коммит `1db73c5`. Это описание v2.2.0 preview. В `main` при аудите находится v2.1.0; опубликованного релиза v2.2.0 нет.

## Структура и выполнение

Основная логика остаётся в `IntelWiFiBTManager.ps1`: выбор языка, журнал, CIM-инвентаризация, сравнение версий, запрос прав администратора, подготовка и запуск установщиков. Это выполняемый скрипт, а не библиотечный модуль.

| Путь | Реальная роль |
| --- | --- |
| `tools/ConsoleUi.ps1` | Этапы, статусы, безопасный выбор. Подключение интерфейса ещё не завершено во всех сценариях. |
| `data/*.json` | Закреплённые сведения о нескольких пакетах. Не динамический онлайн-каталог всего Intel. |
| `tools/Get-InfDriverReport.ps1` | Чтение распакованных INF и создание JSON с моделями/версиями. |
| `tools/Compare-InfDriverReports.ps1` | Сопоставление ID, версий, архитектуры и секций Windows двух отчётов. |
| `tools/Test-DriverPackage.ps1` | Отдельные проверки хеша, подписи CAT, связи INF/CAT и INF/архива. |
| `tools/Test-DriverCandidate.ps1` | Объединение сравнения, аудита пакета и необязательной сверки установленного устройства Windows. |
| `tools/Test-DriverCatalogue.ps1` | Проверка структуры и ограничений локального каталога. |
| `tools/Invoke-*ReadOnlyCheck.ps1` | Исследовательские проверки закреплённых Wi-Fi/BT пакетов без установки драйвера. |
| `tools/Install-LocalSignTool.ps1` | Добровольная локальная подготовка Microsoft SignTool. |
| `tests/` | Самостоятельные PowerShell-сценарии, включая безопасные тесты и отдельные интеграционные испытания. Pester не требуется. |

## Режимы и покрытие

| Режим | Источник и поведение | Ограничение |
| --- | --- | --- |
| `-Inventory` | CIM: платформа и выбранные классы Intel-устройств; без UAC | Наличие устройства не означает поддержку обновления. |
| `-CheckUpdates` | Установленная версия из Windows, сохранённые данные и при необходимости таблицы FirstEverTech | Может обращаться к сети за таблицами; обычный режим не скачивает пакеты драйверов. |
| `-CheckUpdates -VerifyBluetoothCab` | Дополнительная добровольная загрузка закреплённого CAB для Bluetooth PID_0026 | Проверка файла и версии; установки нет. `-PrepareSignTool` добавляет предложение подготовки инструмента. |
| `-CheckUpdates -CandidateManifest ...` | Проверка заранее подготовленных локальных кандидатов | Не поиск новых выпусков и не независимый установщик. |
| `-Graphics` | Один Intel HD/UHD/Iris Plus, выбранные Core 7–10, Windows 10/11 x64; закреплённый пакет | SHA-512 и подпись Intel перед запуском; окончательное решение о совместимости принимает Intel Setup. Это не полная база PCI ID. |
| Обычный запуск | NuGet/PowerShell Gallery, загрузка и запуск FirstEverTech | Установка Wi-Fi/BT делегирована внешней утилите. |
| `-Silent` | Та же внешняя утилита с `-auto`; уже нужны права администратора | Может устанавливать без вопросов; не режим проверки. |

Графика Core 6 имеет только исторический ориентир. Core 11–14 и Arc/Core Ultra направляются на ручную проверку; установка в этих ветках не реализована. Неизвестные ID не должны получать пакет по сходному названию. Чипсет, BIOS и микрокод не обновляются.

Для Wi-Fi/BT сохранённый снимок покрывает отдельные AX201 ID; более старый чем 30 дней снимок отключает сравнение до пересмотра. Для остальных поддерживаемых ключей возможен справочный источник FirstEverTech. Версия из таблицы не доказывает применимость конкретного пакета.

## Границы доверия

- Graphics: закреплённые версия, адрес и SHA-512 в менеджере; `data/driver-packages.json` сверяется с ними. Проверка метаданных при `-CheckUpdates` не равна проверке скачанного файла.
- Официальные пилотные пакеты Intel: отдельные JSON и скрипты проверок закреплённых ZIP/EXE. Это не автоматическое обнаружение будущих релизов.
- Bluetooth CAB: Microsoft delivery host и закреплённый SHA-256. Для исследуемого пакета каталожная запись Microsoft и публикация Intel не установлены; нельзя обещать больше, чем показывают отдельные поля аудита.
- SignTool: закреплённый Microsoft SDK BuildTools из NuGet, SHA-512 пакета и проверка подписи Microsoft у исполняемого файла.
- FirstEverTech: менеджер сверяет имя, автора и URL проекта с метаданными PSGallery/скрипта; это не криптографическое подтверждение происхождения.

`Test-DriverCandidate.ps1` возвращает `REJECT`, `MANUAL_REVIEW`, `NO_NEWER_VERSION` или `CANDIDATE_FOR_REVIEW`. Даже последний результат не разрешает автоматическую установку. Равная версия может дать `NO_NEWER_VERSION` при ещё неполных проверках происхождения: поля пакета нужно читать отдельно. Полнота пакета, Windows PnP ranking и ограничения OEM не доказаны этими тестами.

## Файлы, журнал и интерфейс

Менеджер использует `%LOCALAPPDATA%\IntelWiFiBTManager`:
- `Logs`: PowerShell transcript; продолжение после UAC и код завершения.
- `Work/<GUID>`: временные файлы отдельного запуска, очистка при завершении.
- `Tools/SignTool/<version>`: сохранённый инструмент, не обычная временная папка.

Пользовательский `-GraphicsInstallerPath` не принадлежит менеджеру и не должен удаляться. Уже реализованная очистка временного запуска отличается от будущего управления накопленным кэшем в Issue #2.

Строки пока находятся непосредственно в скриптах: функция `L` в менеджере, `Say`/условия в инструментах. Единого языкового каталога нет. `Confirm-ManagerAction` делегирует выбор общему UI или использует встроенный вариант при отсутствии `tools`. Отсутствие цвета не должно менять смысл. Сторонние окна остаются интерфейсами их авторов. Transcript не гарантирует запись всего содержимого внешнего GUI.

Предложение перезагрузки после Graphics зависит от подтверждения версии или принимаемого кода установщика; это эвристика предложения, не универсальное определение pending reboot. Реальная перезагрузка выполняется только после подтверждения.
